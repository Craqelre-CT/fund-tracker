# 📈 基金涨幅追踪

一个纯前端的单页应用，用于记录个人基金净值金额，自动计算每次涨跌幅与整体涨跌幅，并以折线图可视化趋势。所有数据保存在浏览器本地，无需后端、无需登录。

## ✨ 功能特性

- **记录管理**：添加（年、月、日、金额）记录，默认填入当天日期，可修改；支持删除任意一条记录。
- **日期校验**：自动校验日期合法性（如 2 月 30 日会被拒绝）。
- **涨幅统计**：
  - 顶部卡片展示「最新金额」「整体涨跌幅」「记录数」
  - 单次涨跌幅 = (本次 − 上次) / 上次 × 100%
  - 整体涨跌幅 = (末次 − 首次) / 首次 × 100%
  - 红涨绿跌，符合 A 股习惯
- **折线图**：基于 Chart.js，按日期自动排序重绘，悬停查看日期、金额与本次涨跌幅。
- **本地持久化**：数据存储在 `localStorage`，刷新页面不会丢失。

## 🚀 快速开始

本项目为单文件应用，无需安装依赖。

### 方式一：本地打开

直接用浏览器打开 `index.html` 即可使用。

> 注：折线图依赖 Chart.js CDN，首次打开需联网。

### 方式二：本地服务器（推荐）

```bash
# 在项目根目录执行
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000/
```

## 🛠️ 技术栈

- 原生 HTML / CSS / JavaScript（无构建工具）
- [Chart.js 4.x](https://www.chartjs.org/)（折线图渲染，CDN 引入）
- `localStorage`（数据持久化）

## 🔒 数据说明

- 所有记录仅保存在**当前浏览器**的 `localStorage` 中。
- 清除浏览器缓存或更换设备/浏览器后，数据将丢失，请注意备份。
- 不向任何服务器上传数据。

## 📝 使用示例

1. 打开网页，日期默认为今天。
2. 在「金额」输入框填入当日基金净值，点击「添加」。
3. 重复记录多个日期后，折线图与涨跌幅将自动更新。
4. 如需删除某条记录，点击明细表该行的「删除」按钮。
